
LANGKAH LENGKAP DEPLOY KE GITHUB PAGES (GRATIS SELAMANYA, NO KREDIT):

=== CARA 1: UPLOAD LANGSUNG (PALING GAMPANG, 2 MENIT) ===

1. Buka https://github.com/new
   - Repository name: generus-mahkota
   - Public (biar Pages gratis)
   - Centang Add README
   - Create repository

2. Di halaman repo baru, klik "Add file" > "Upload files"

3. Drag & drop SEMUA file dari folder ini:
   - index.html (WAJIB - ini aplikasi PRO)
   - simple.html
   - logo-192.png, logo-512.png, logo.jpg, logo.png
   - manifest.json
   - .nojekyll
   - README.md

4. Klik "Commit changes"

5. Masuk ke Settings (tab atas) > Pages (menu kiri)
   - Build and deployment > Source: Deploy from a branch
   - Branch: main, Folder: / (root)
   - Save

6. Tunggu 1-2 menit, refresh halaman Settings > Pages
   - Akan muncul link: https://USERNAME.github.io/generus-mahkota/
   - Klik link -> APLIKASI SUDAH LIVE!

7. Share link ke admin kelompok!

=== CARA 2: PAKAI GITHUB DESKTOP (Jika mau edit nanti) ===

1. Install GitHub Desktop
2. Clone repo generus-mahkota
3. Copy file index.html ke folder
4. Commit & Push
5. Otomatis deploy
